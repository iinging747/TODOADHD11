📘 Anthropic API 키 발급 가이드

한 번만 받으면 끝

사진·링크·대화에서 AI가 일정 추출하려면 Anthropic Claude API 키가 필요해요. 무료로 받을 수 있고 사용량만큼만 (몇 십원 단위) 과금돼요.

  1. console.anthropic.com 접속
    https://console.anthropic.com
  2. Google 또는 이메일로 회원가입 (무료, 1분이면 끝)
  3. 로그인 후 → 왼쪽 메뉴에서 "API Keys" 클릭
  4. "Create Key" 버튼 클릭
  5. 키 이름 입력 (예: "정신차려 다이어리") → 생성
  6. ⚠ sk-ant- 로 시작하는 키 복사 — 이 화면 한 번만 보여줘요. 안 보이면 다시 만들어야 함
  7. 이 앱에 돌아와서 "Anthropic API 키" 칸에 붙여넣기 → 자동 저장

💸 비용

가입 시 무료 크레딧 $5 정도 제공돼요.
일정 추출 한 번 = 대략 0.01~0.02 달러 (1~30원). $5으로 수백 번 가능.
다 쓰면 신용카드 등록 (사용량만큼만 자동 결제). 매월 사용량 한도도 설정 가능.

🔒 보안

키는 본인 브라우저(localStorage)에만 저장돼요 — 서버에 안 올라감.
혹시 키가 유출됐다 싶으면 console.anthropic.com에서 그 키 삭제하고 새로 발급.
